# Web Server using Docker

## Technologies
- Docker
- Nginx
- AWS EC2
- Linux

## Architecture

Client
   ↓
AWS EC2
   ↓
Docker Container
   ↓
Nginx
   ↓
Web Application

## Docker Commands

docker build
docker run
docker ps
docker stop
docker start
docker logs
docker stats

## Deployment

Application deployed on AWS EC2 using Docker.
